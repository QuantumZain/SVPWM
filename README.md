# SVPWM
Interactive GUI to illustrate Space Vector Pulse Width Modulation. By changing the magnitude and direction of the reference vector, the resulting PWM ABC signals are seen along with sector contribution of each state vector.

# Usage
Use the mouse to control the direction of the reference voltage vector, the contribution of each space vector state is shown by the pulses in the middle and then using these pulses the final timings for the resulting PWM ABC signals needed to drive a motor are shown on the right.
